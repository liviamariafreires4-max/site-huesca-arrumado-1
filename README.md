# Projeto — Hotel Palace Huesca

Site estático adaptado ao modelo HTML/CSS anterior, com conteúdo obtido do site oficial do Hotel Palace Huesca e sem copiar o layout atual.

## Como abrir

1. Extraia o ZIP inteiro.
2. Abra a pasta no VS Code.
3. Execute `index.html` com a extensão Live Server.

## Paleta

A cor principal é `#09345e`. As demais variações estão no começo de `css/global.css`.

## Imagens

Não foram copiadas imagens do site. Os espaços estão indicados por blocos com borda tracejada. Consulte `img/LEIA-ME.txt`.

## Páginas

- `index.html` — apresentação do hotel
- `quartos.html` — seis opções de quartos e valores publicados
- `localizacao.html` — endereço e pontos próximos
- `sobre.html` — administração, empresa, CNPJ e história
- `atendimento.html` — atendimento 24h e acessibilidade
- `faq.html` — perguntas frequentes
- `reserva.html` — contato para reserva

## Observações de conteúdo

- O site oficial consultado apresenta pequenas divergências na composição das camas entre a página inicial e a página de quartos. O projeto usa as configurações exibidas na página inicial e recomenda confirmação na reserva.
- Preços e disponibilidade podem mudar. O aviso foi mantido na página de quartos.
- As URLs de Facebook e Instagram não ficaram identificáveis no conteúdo textual acessível; os links estão como `#` para preenchimento posterior.
- O endereço foi preenchido como Avenida Brasil, nº 550, conforme a página inicial oficial.
